# UABankSim 🏦

UABankSim — глибокий event-driven симулятор комерційного банку в Україні. Ви —
голова правління, і ваш продукт — гроші, а головний інструмент — управління
ризиком.

На відміну від класичних бізнес-симуляторів, тут кожна дія проходить через
справжню бухгалтерію: видача кредиту, підкріплення каси, зарплата касира —
усе це проводки в Головній книзі, які змінюють Баланс і Звіт про фінансові
результати.

## Стан проєкту

Реалізовано **ядро симуляції та вертикальний зріз роздрібного бізнесу**:
рушій часу, шина подій, Головна книга з подвійним записом, план рахунків НБУ,
звітність, пруденційні нормативи, історичні макродані та чотири бізнес-модулі.
Це фундамент, на який решта механік із ТЗ (карти й еквайринг, мережа
відділень, VIP-банкінг, інкасація, фінмоніторинг) додаються як модулі, без
переписування ядра.

## Швидкий старт

```bash
npm install
npm run build
npm run sim -- --scenario sandbox --weeks 96
```

Корисні прапорці:

```bash
npm run sim -- --help                       # довідка та список сценаріїв
npm run sim -- -s crisis-manager -w 144     # кризовий сценарій 2022 року
npm run sim -- -s sandbox --passive         # банк, яким ніхто не керує
npm run sim -- -s career --seed 42 --quiet  # без стрічки подій
```

## Архітектура

```
packages/
  core/      ядро: гроші, Головна книга, шина подій, календар, нормативи, рушій
  data/      історичні ряди НБУ та сценарії старту
  modules/   бізнес-модулі: депозити, кредити, казначейство, витрати, акціонери
  cli/       консольний прогін сценарію зі звітністю
```

Ядро **не знає**, що таке депозит, картка чи броньований автомобіль. Воно вміє
рахувати час, вести Головну книгу і розносити події. Усе інше — модулі, які
реєструються у сценарії й спілкуються виключно через шину подій. Модуль ніколи
не імпортує інший модуль.

### Такт симуляції

Один такт — **тиждень**. Чотири тижні складають фінансовий місяць (закриття
періоду, нарахування резервів, зарплати), три місяці — квартал (розбір польотів
у раді директорів), дванадцять — фінансовий рік із закриттям рахунків доходів
і витрат.

Кожен тиждень виконується строго фазами, і цей порядок — і є "фізика" банку:

| Фаза | Що відбувається |
| --- | --- |
| `week-begin` | макроекономіка, рішення регулятора, ринкові умови |
| `week-main` | бізнес: продажі, видачі, зняття, платежі |
| `week-accrual` | нарахування відсотків, резервів, амортизації |
| `week-treasury` | казначейство закриває розрив ліквідності |
| `week-end` | звітність, нормативи, перевірка умов програшу |

Казначейство свідомо йде **після** нарахувань: у справжньому банку рішення про
овернайт приймають, знаючи підсумок дня, а не до нього.

### Головна книга

Жодна ігрова механіка не змінює баланс напряму. Механіка формує проводку,
проводка проходить перевірку «дебет = кредит у розрізі кожної валюти» — і лише
тоді потрапляє в книгу. Тому баланс не може «поїхати» через баг у механіці: він
або зійдеться, або проводку буде відхилено.

Гроші зберігаються цілими копійками — жодних `float`, які накопичують похибку
на десятках тисяч проводок.

План рахунків — підмножина плану рахунків банків України (класи 1–7): готівка,
коррахунок в НБУ, обов'язкові резерви, депсертифікати, ОВДП, міжбанк,
рефінансування, кредити й депозити клієнтів, резерви під знецінення, капітал,
доходи та витрати.

## Що вже працює

- **Час і сценарії** — тижневий такт, фінансові періоди, три сценарії старту з ТЗ.
- **Головна книга** — подвійний запис, мультивалютність, контрольна рівність,
  річне закриття, Баланс і Звіт про фінансові результати з реальних сальдо.
- **Нормативи НБУ** — Н1, Н2, Н3, Н6, активи зважені на ризик, NPL, покриття
  резервами; порушення потрапляють у стрічку подій.
- **Макроекономіка** — історичні ряди облікової ставки, інфляції та курсу з 2013
  по 2025 рік із тижневою інтерполяцією; індекс стресу відтворює кризи
  2014–2015, 2020 і 2022 років.
- **Депозити населення** — строкові вклади когортами, поточні рахунки, еластичний
  попит за ставкою, пролонгація, паніка вкладників і черги в касі.
- **Роздрібне кредитування** — кеш-кредити й кредитні картки, поріг скорингу як
  головний важіль ризик-апетиту, міграція прострочення за стадіями МСФЗ 9,
  резерви, списання безнадійних боргів.
- **Казначейство** — обов'язкові резерви, підкріплення каси з витратами на
  інкасацію, депсертифікати НБУ, міжбанк овернайт із лімітом за довірою ринку,
  рефінансування НБУ під заставу портфеля.
- **Витрати та маркетинг** — мережа відділень і головний офіс як центри витрат,
  конверсія реклами у впізнаваність бренду зі спадною віддачею.
- **Акціонери** — річні цілі по ROE і CIR, квартальний перегляд, звільнення
  після трьох провалених кварталів поспіль.
- **Автопілот** — референсна політика, яка приймає ті самі рішення, що й гравець:
  потрібна для балансування і як жива документація поверхні рішень.

## Що далі

Наступні модулі за ТЗ, які підключаються без змін у ядрі: карткові продукти й
еквайринг (on-us транзакції, interchange, власний процесинг проти аутсорсу),
типологія мережі відділень, VIP-банкінг, власна служба інкасації, фінансовий
моніторинг із повзунком жорсткості, кредитування МСБ і корпорату, зарплатні
проєкти, мобільний застосунок як дерево прокачки, інспекції НБУ та «чорні
лебеді».
